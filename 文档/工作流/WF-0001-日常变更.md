# WF-0001 日常变更

Status: Active
Kind: Workflow
Workflow ID: WF-0001
Scope: AtlasPay workspace / 非编码变更
Owner: Codex
Updated: 2026-08-05
Depends On:
- WORKFLOW_CONTRACT.md

## Trigger

修改正式文档、任务控制或治理配置，且不改变源码、数据、API、构建或技术执行逻辑。

## Input

用户目标、当前状态、唯一事实所有者、可观察验收，以及仅在受控或跨会话变更中存在的任务入口。

## Output

授权范围内的最小文档增量、匹配的验证证据，以及由 WF-0004 形成的完成、取消或未完成结果。

## Actions

即时变更执行 `ACT-CLASSIFY-REQUEST` -> `ACT-ROUTE-CONTEXT` -> `ACT-VERIFY-BASELINE` -> `ACT-EXECUTE-CHANGE` -> `ACT-VERIFY-RESULT` -> WF-0004。

受控文档变更增加 `ACT-REGISTER-TASK`；同回合完成也不省略登记。

## Key Constraints

- 不创建 ChangePlan；若需要编码或技术迁移，重新分类到 WF-0002。
- 只修改拥有本次事实的唯一文档，不顺带整理其他内容。
- 正式文档或治理入口变化时执行 `ACT-VALIDATE-DOCS`。

## Stop When

需要修改源码、改变产品或安全边界、无法确定唯一所有者，或用户目标与当前规范冲突时停止并重新分类或确认。
