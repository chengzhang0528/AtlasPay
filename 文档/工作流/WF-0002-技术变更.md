# WF-0002 技术变更

Status: Active
Kind: Workflow
Workflow ID: WF-0002
Scope: AtlasPay workspace / 编码与技术迁移
Owner: Codex
Updated: 2026-08-05
Depends On:
- WORKFLOW_CONTRACT.md

## Trigger

修改源码、数据、API、构建、治理校验代码或技术执行逻辑，或者任务需要编码级方案才能安全推进。

## Input

当前任务、已验证基线、授权边界、成功标准、停止条件，以及实际命中的长期事实所有者。

## Output

授权范围内的实现增量、验证后的目标态、必要的长期事实更新，以及 WF-0004 形成的最终结果；受控变更必须与 Active ChangePlan 一致。

## Actions

即时变更执行 `ACT-CLASSIFY-REQUEST` -> `ACT-ROUTE-CONTEXT` -> `ACT-VERIFY-BASELINE` -> `ACT-EXECUTE-CHANGE` -> `ACT-VERIFY-RESULT` -> WF-0004。

受控变更增加 `ACT-REGISTER-TASK` 和编码前的 `ACT-OPEN-PLAN`；持续阻断时执行 `ACT-CAPTURE-BLOCKER` 并进入 WF-0003。

## Key Constraints

- 即时变更必须满足 WorkflowContract 的全部即时条件，不登记任务、不创建方案。
- 受控变更编码前必须有 `Workflow: WF-0002` 的 Active ChangePlan，具体顺序与验证只写在该方案。
- 不扩张服务、权限、产品边界、数据模型或外部依赖；超出授权时停止。
- 长期文档只在定向命中或事实变化时更新，不把每次代码改动都写成长期事实。

## Stop When

基线无法验证、关键选择未决、需要新权限或秘密、方案范围不足、验证失败，或继续会进入未授权工作时停止。
