# WF-0003 调查与阻断

Owner: Codex
Updated: 2026-08-05
Depends On:
- WORKFLOW_CONTRACT.md

## Trigger

用户要求只读调查、诊断或评审，或者当前任务因外部依赖、缺失权限、事实冲突或验证失败而无法继续，并可能跨会话保留。

## Input

问题描述、当前任务、可读取证据、允许的诊断边界、已尝试路径和下一步所需条件。

## Output

有证据支持的结论、明确未知项和建议；跨会话阻断还必须同步任务并创建或更新唯一 Issue。未获实现授权时不产生修复性变更。

## Actions

执行 `ACT-CLASSIFY-REQUEST` -> `ACT-ROUTE-CONTEXT` -> `ACT-VERIFY-BASELINE` -> `ACT-VERIFY-RESULT`；跨会话阻断再执行 `ACT-REGISTER-TASK` 和 `ACT-CAPTURE-BLOCKER`。获得实现授权后重新分类。

## Key Constraints

- 诊断不自动授权修复、外部写操作、权限申请或范围扩张。
- 临时错误、命令输出、日志和聊天不创建 Issue。
- Issue 只保存恢复所需的当前证据、影响、边界和下一入口。

## Stop When

证据不足且继续需要破坏性动作、新权限、秘密、外部协调或用户选择时停止并报告阻断，不用推测填补结论。
