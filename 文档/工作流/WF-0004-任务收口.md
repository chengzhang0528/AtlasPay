# WF-0004 任务收口

Owner: Codex
Updated: 2026-08-05
Depends On:
- WORKFLOW_CONTRACT.md

## Trigger

任一会改变工作空间的任务准备报告完成、取消，或者当前回合结束但任务仍受阻。

## Input

当前任务、工作空间增量和验收结果，以及仅在实际存在时提供的活动 ChangePlan/Issue、长期事实所有者和文档验证状态。

## Output

三种互斥结果之一：完成并清理活动入口；取消且准确保留或清除已生效事实；未完成并保留可恢复入口。最终汇报必须可核验。

## Actions

始终执行 `ACT-VERIFY-RESULT` 和 `ACT-REPORT-RESULT`。按真实触发执行 `ACT-CLASSIFY-KNOWLEDGE`、`ACT-RECONCILE-KNOWLEDGE`、`ACT-RESOLVE-ACTIVITY`、`ACT-ARCHIVE-RESULT` 与 `ACT-VALIDATE-DOCS`。

## Key Constraints

- 全部实际验收与已触发文档门禁通过后，才可删除 ChangePlan、Issue 或完成任务项。
- 没有长期增量时不创建占位文档；有已生效事实时不能以取消规避归位。
- 未完成时保留唯一任务入口、必要活动文档和下一可执行条件。
- 收口前精确检查改动归属；提交前精确暂存，推送前 fetch，发现分叉或并发改动即停止说明。

## Stop When

验证失败、长期事实未归位、活动文档仍被需要、引用校验失败或完成条件不完整时，转为未完成结果。
